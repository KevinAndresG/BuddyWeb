Guía rápida

Listo en 3 minutos

Descarga e instala

  1. Descarga Buddy-Setup.exe (descarga directa, ~120 MB).
  2. Ejecútalo y elige la carpeta. Crea accesos en el Escritorio y el Menú Inicio.
  3. Si Windows SmartScreen avisa de "editor desconocido": Más información → Ejecutar de todas formas (el instalador no está firmado, es normal en proyectos personales).

Consigue tu API key gratis de Groq

  1. Entra a console.groq.com y crea una cuenta (no pide tarjeta).
  2. Genera una API key (empieza por gsk_).
  3. En Buddy: pasa el mouse por encima → ⚙ Ajustes → pégala en Groq API key → Guardar.

La misma key sirve para el cerebro y para escucharte. Sin key, los comandos locales siguen funcionando.

Háblale

Haz clic en el robot o pulsa Ctrl+Alt+B y habla. Se detiene solo cuando te callas. Para escribir: Ctrl+Alt+T. Arrastra al bot para moverlo; recuerda su posición. Esc lo calla.

Preguntas frecuentes

¿Dudas?

¿De verdad es gratis? ¿Dónde está la trampa?

No hay trampa. Buddy usa el plan gratuito de Groq (IA y reconocimiento de voz) y las voces gratuitas de Edge. No hay versión premium, ni anuncios, ni pagos dentro de la app.

¿El plan gratis de Groq tiene límites?

Sí, unos ~8000 tokens por minuto por modelo. Para uso normal sobra. Si te pasas, Buddy cambia a un modelo más pequeño o te pide esperar unos segundos.

¿Funciona sin internet?

Los comandos instantáneos y la voz de Windows sí. Para conversar y entenderte por voz necesita internet, salvo que uses Ollama en local.

¿Puedo usar mi plan de Claude?

Sí. En Ajustes → Cerebro elige "Claude". Usa el CLI oficial con tu sesión (claude /login). Es más lento pero muy capaz.

¿En qué apps puede pulsar botones o leer la pantalla?

En las que exponen accesibilidad de Windows: navegadores, WhatsApp, Calculadora, Office y la mayoría de apps. En juegos o apps con interfaz propia usa la visión o atajos de teclado.

Lo cerré y no lo encuentro

Si lo ocultaste (🙈) sigue en la bandeja del sistema, junto al reloj. Si saliste (✕), ábrelo desde el acceso directo "Buddy". En Ajustes puedes hacer que inicie con Windows.

¿Cómo lo desinstalo?

Configuración de Windows → Aplicaciones → Buddy → Desinstalar.
